[![npm version](https://img.shields.io/npm/v/persian-date-native?color=6366f1&style=flat-square)](https://www.npmjs.com/package/persian-date-native)
[![npm downloads](https://img.shields.io/npm/dm/persian-date-native?color=22c55e&style=flat-square)](https://www.npmjs.com/package/persian-date-native)
[![coverage: 100%](https://img.shields.io/badge/coverage-100%25-brightgreen.svg?style=flat-square)](https://github.com/muhamadzolfaghari/persian-date-native)

High-performance, **zero required runtime dependencies** Persian (Jalali/Shamsi) date engine extending native JavaScript `Date` with a Day.js-style fluent API and Day.js plugin support. Benchmarking up to **89M+ pure conversion ops/sec on Node.js/V8**.

```ts
import { persianDate } from 'persian-date-native';

const d = persianDate(new Date(2024, 0, 15));
console.log(d.format('YYYY/MM/DD')); // 1402/10/25
console.log(d.toISOString());        // 2024-01-15T...
```
