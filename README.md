## Frontend architecture and modernization

I enjoy working on systems where the architecture needs to evolve while existing product behavior must remain stable.

My approach includes:

* Feature-based architecture with explicit ownership boundaries
* Separating presentation from business and API logic
* Replacing duplicated code with reusable components and hooks
* Preserving existing behavior during gradual migrations
* Documenting architectural decisions and constraints
* Testing critical journeys before and after refactoring
* Using incremental delivery instead of risky full rewrites

I pay close attention to loading, empty, error, retry, authentication, and edge-case states because they are part of the actual product—not secondary details.

## Selected projects

### [React Under the Hood](https://github.com/muhamadzolfaghari/react-under-the-hood)

A practical exploration of React internals through building a simplified React implementation from scratch. It demonstrates rendering, virtual DOM concepts, hook execution order, state management, `useState`, and `useEffect`.

### [ESLint Import Groups](https://github.com/muhamadzolfaghari/eslint-import-groups)

An ESLint configuration for enforcing clean and predictable import organization. It separates built-in, external, and internal dependencies while applying alphabetical ordering and consistent spacing between groups.

### [Retry Pattern in JavaScript](https://github.com/muhamadzolfaghari/retry-pattern-js)

An implementation of the retry pattern for handling transient asynchronous failures. It demonstrates configurable retry limits and exponential backoff for API requests and other asynchronous operations.

### [Common JavaScript Validations](https://github.com/muhamadzolfaghari/most-common-js-validations)

A collection of reusable validation utilities for Iranian applications, including personal and company national IDs, mobile and telephone numbers, and geographic coordinate boundaries.

### [Persian Date](https://github.com/mu-utils/persian-date)

A TypeScript library for working with Persian and Gregorian calendars. It provides calendar conversion, formatting, date arithmetic, comparisons, time-zone support, and leap-year detection through a familiar JavaScript date API.

### [Deferred in JavaScript](https://github.com/muhamadzolfaghari/deferred-in-js)

A practical explanation of deferred objects and manual Promise control, demonstrated through asynchronous HTTP-client initialization and image-loading examples.
